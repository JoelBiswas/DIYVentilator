## The Concept
The job of a ventilator is to be able to pump out a fixed volume of air at a fixed number of times per minute. These devices became extremely in demand during the 2020 pandemic. Traditional ventilator systems are very expensive, so I attempted to create a cheap, 3D-printable design that uses standard hardware such as nuts and bolts.

## Guide to this Repo
This repo contains several top-level files and folders providing documentation for this project

**JOURNAL.md** - Contains a log of my progress on this project

**BOM.csv** - Detailed Bill of Materials for this project

**Demos** - Demo video of the final product

**CAD** - Contains images of the CAD model, STEP files for each part and assembly, and a link to the public Onshape document for this project

**Code** - Contains all firmware for the ventilator

**3D Printing** - Contains STL Files for all 3D printable parts, as well as pre-sliced files for the FlashForge Adventurer 5M
